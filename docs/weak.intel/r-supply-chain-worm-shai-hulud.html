Maintainer_PhishingcapabilityVECTOR (initial access): credential-phishing of package maintainers via lookalike registry domains to steal npm publish tokens - the human foothold that seeds the automated spread.
TruffleHog_WeaponizedcapabilityVECTOR (collection): the worm bundles TruffleHog - a legitimate secret-scanning tool - to sweep the victim host/repo for tokens and cloud keys. Dual-use: the same scanner defenders run to find leaked secrets.
CICD_Runner_PersistencecapabilityVECTOR (persistence): registers the victim as a self-hosted GitHub Actions runner, giving the attacker durable code execution inside the CI environment that survives the initial package removal.
Provenance_ForgerycapabilityVECTOR (defense evasion): Mini forges npm provenance/attestation metadata so a poisoned package appears to have a trustworthy build origin - defeating the exact control introduced to stop supply-chain tampering.
Disable_Install_ScriptscontrolMITIGATION: install with lifecycle scripts disabled (`npm ci --ignore-scripts`, or `ignore-scripts=true`) so a poisoned package cannot execute on install. Directly neutralizes the primary infection mechanism.
Trusted_Publishing_OIDCcontrolMITIGATION: publish via short-lived OIDC 'trusted publishing' + granular/expiring tokens instead of long-lived PATs; enforce 2FA/passkeys on registry accounts. Removes the reusable-token loot the worm needs to republish.
Dependency_Pinning_CooldowncontrolMITIGATION: pin exact versions via lockfile + integrity hashes and quarantine brand-new releases for a cooldown window - so a malicious patch bump is not pulled the moment it is published.
NPM_Provenance_AttestationcontrolMITIGATION (partially defeated): sigstore-backed npm provenance ties a package to its source + build. Strong against blind tampering - but Mini's forgery shows attestation is only as good as the trust in the signing path.
Ephemeral_CI_LeastPrivcontrolMITIGATION: ephemeral, isolated CI runners with least-privilege scoped secrets and egress filtering - so a compromised build cannot persist as a runner, read every secret, or phone home to GitHub-hosted drops.
Secret_Rotation_ScanningcontrolMITIGATION (response): continuous secret scanning + fast rotation. Because dumped secrets are public immediately, detection-to-rotation time is the whole game post-compromise.
