Blue-team methods: why they work, where they fail, weaponizing the guard

Cited structured data lives in the sibling .json. Narrative is the map, not a dossier.

Entities (18)

NameTypeNotes
FIDO2_WebAuthncontrolPhishing-resistant MFA. Secret never leaves the authenticator. Works vs credential phishing and OTP AiTM. Fails vs session-cookie theft AFTER auth, or compromised authenticator supply chain.
EDR_XDRcontrolEndpoint telemetry + behavioral detection. Works vs known malware and many living-off-land patterns. Fails vs BYOVD/EDR-killers, signed-driver abuse, and when the EDR process itself is injectable.
Network_SegmentationcontrolBlast-radius limit. Works vs worm/ransomware east-west spread. Fails when identity IS the network (token/TGT replay across segments).
Immutable_BackupscontrolRecovery from encryption. Works if backup plane is identity-isolated. Fails if AD/backup-admin is taken first (Conti playbook).
Patch_ManagementcontrolCloses known n-days. Works vs mass KEV exploitation (Exchange Proxy*, MOVEit, VPN). Fails vs 0-day and against orgs that cannot patch appliances.
Memory_Safe_RewritescontrolRemoves a class of bugs (CISA/NSA memory-safety guidance). Works vs memory-corruption worms. Fails vs logic/authz/supply-chain.
Allowlisting_PPLcontrolApplication control + Protected Process Light for security services. The documented mitigation for DoubleAgent-class verifier-DLL injection into AV.
Vulnerable_Driver_BlocklistcontrolMicrosoft HVCI/WDAC blocklist vs BYOVD. Coverage lags newly-abused signed drivers (AuKill, EDRKillShifter).
SIEM_Detection_EngineeringcontrolLog correlation. Works when telemetry exists and detections are tuned. Fails if EDR is killed first or logs are not collected from appliances.
Threat_Intel_SharingcontrolCISA KEV, ISAC, vendor intel. Compresses n-day window. Does not create a 0-day defense.
PQC_MigrationcontrolHybrid TLS + ML-KEM/ML-DSA. Works for NEW sessions after cutover. Does not un-harvest old ciphertext (HNDL already incurred).
CrowdStrikevendorEDR/XDR vendor. Dual-use recursion: the same telemetry that defends is a surveillance dataset. July 2024 content-update outage is a concentration-risk exhibit.
MandiantvendorIR/attribution. Google-owned. APT1 report (2013) first public naming of a PLA unit.
MicrosoftvendorOS, identity, mail, EDR (Defender), cloud. Recurring target AND default protector. Dual-use node.
CISAagencyUS civilian cyber defense. KEV catalog, joint advisories. Does not operate offensive access.
Citizen_LabaffiliateAcademic forensic lab (Toronto). Primary public technical source on mercenary spyware.
DoubleAgentmalware2017 Cybellum: Application Verifier DLL injection into AV processes. Requires prior admin. Mitigation = PPL.
BYOVDcapabilityBring-Your-Own-Vulnerable-Driver. Kernel via legitimately signed vulnerable drivers. EDR-killers (AuKill, EDRKillShifter/RansomHub).
