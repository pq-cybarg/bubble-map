Reading the emergent layers

The mixer dual-use is data-driven. Nothing in the pipeline hand-labels a laundering rail. Tornado_Cash and Samourai_Wallet appear in the dual-use set above only because the graph records them both protecting Financial_Privacy and being targeted by OFAC/DOJ/FinCEN — the same test that flags CALEA and EternalBlue. Lazarus using Tornado Cash to wash stolen funds is a uses edge, not a moral tag.

Protocol vs person. The accountability sinks separate the code from its authors: Tornado_Cash lands in got-away (OFAC's designation was vacated in 2024; the immutable contracts persist on-chain) while Roman_Storm lands in did-not-get-away (convicted 2025). A sanction against autonomous code is not the same as a conviction of a developer, and the graph refuses to conflate them.

The marketplace tier is a class, not a headline. Darknet_Market is a capability node that Silk_Road, AlphaBay, and Nexus instantiate; IABs feed it wholesale access. The instances sit in did-not-get-away (Ulbricht, Operation Bayonet) but the class keeps a live degree — the graph's way of showing that takedowns remove instances, not the model.
