Quantum error correction

Error correction is the gate to usefulness: physical qubits are far too noisy, so many are combined into fewer, more reliable LOGICAL qubits. Exponential error suppression only kicks in BELOW a physical-error threshold (~1% for surface/qLDPC). 2024-26 crossed that line experimentally; the frontier is now overhead (qLDPC), leakage, universality (magic states / transversal gates), and real-time decoding.

Concepts

Threshold. The physical error rate below which adding qubits reduces logical error. ~1% for surface code and high-rate qLDPC (independent depolarizing noise).
Overhead. Physical qubits per logical qubit. Surface code ~121:1 at distance-11 (plus ancillae); qLDPC far lower; bosonic cat codes push to single digits for one error type.
Break-even. When a logical qubit outlives its best physical qubit - the minimum bar for QEC to help. Crossed by Google Willow (2.4x).
Magic states / universality. QEC alone protects only Clifford gates; magic-state cultivation or transversal non-Clifford gates are needed for a universal fault-tolerant computer.
