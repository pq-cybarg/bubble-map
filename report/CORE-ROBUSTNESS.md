# Circular-financing core - concrete-metric robustness certificate

*Additive re-evaluation. This does NOT replace the published headline core (SCC of 12) or robust core (11) - it stress-tests them against a family of objective, field-based filters so the core is justified by measurement rather than by the hand-set `cancelable` / `declared_circular` flags alone. Generated by `models/graph/core_robustness.py`.*

## Method

Each filter is a predicate on a financial edge using only recorded fields (`amount_usd`, `status`, `cancelable`, `declared_circular`). For each filter the strongly-connected core is recomputed (Tarjan). A node's **robustness score** is the fraction of filters that keep it in the core. The **certified core** is the set of nodes with score 1.0 (in the core under *every* lens); the **plausible core** is the union (in the core under *any* lens).
